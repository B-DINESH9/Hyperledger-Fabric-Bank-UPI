# Hyperledger-Fabric-Bank-UPI

This repository contains the frontend and backend for the Blockchain UPI project.

Quick start (development)

Prerequisites:
- Node.js 18+
- npm

Backend

```powershell
cd backend
npm install
npm start
```

Frontend (development)

```powershell
cd frontend
npm install
npm start
```

Frontend (production build)

```powershell
cd frontend
npm run build
```

Notes
- The frontend dev server proxies API requests to `http://localhost:5001` by default.
- To run both servers locally, start the backend first and then the frontend.
